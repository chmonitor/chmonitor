# chmonitor docs (`apps/docs`)

Documentation site for **docs.chmonitor.dev**, built with
[Fumadocs](https://fumadocs.dev) + **TanStack Start** (Vite). Deployed to
Cloudflare Workers as `chmonitor-docs` — an SSR worker
(`@tanstack/react-start/server-entry`) whose pages are prerendered at build
time by the TanStack Start Vite plugin.

## Standalone install (important)

Like every app except `apps/mcp`, this app is **NOT a member of the root pnpm
workspace** (`pnpm-workspace.yaml` only lists `apps/mcp` and `packages/*`). It
has its own `pnpm-lock.yaml` and its own install step, which keeps the root
`pnpm.overrides` out of its dependency tree:

```bash
cd apps/docs
pnpm install
```

## Develop

```bash
cd apps/docs
pnpm install
pnpm run dev      # http://localhost:3001
pnpm run build    # sync-docs -> generate-og -> vite build (incl. prerender)
pnpm run smoke    # crawl the built/dev site to verify pages resolve
```

## Content

```text
docs/content/**            current docs — the single source of truth, edited by hand
apps/docs/content/docs/    generated by sync-docs.mjs (gitignored)
```

- **Edit docs under `docs/content/**`.** Never edit `content/docs/**` — it is
  regenerated on every build and gitignored.
- `scripts/sync-docs.mjs` (prebuild) transforms `docs/content/**` into the
  Fumadocs content collection: frontmatter keeps `title` (+ optional
  `description`), the body `# Heading` is stripped (Fumadocs renders the title
  from frontmatter), `/docs/…` links are kept (the site serves at the root),
  relative image paths are rewritten to `raw.githubusercontent.com` URLs, and
  per-section `meta.json` files are generated to drive sidebar order/names.
- Information architecture: three top-level tabs (Fumadocs layout tabs,
  `tabMode: 'auto'`); page URLs are `/<tab>/<section>/<page>`. Old flat URLs
  redirect via `DOC_REDIRECTS` in `src/routes/$.tsx`.

There is **no per-release versioning** — the working docs are served directly at
the site root.

### Raw markdown & AI endpoints

Every page has a raw-markdown sibling: `/deploy/docker` → `/deploy/docker.md`
(served by `src/routes/{$}[].md.ts`). `/llms.txt` and `/llms-full.txt` expose
structured indexes of all pages for AI crawlers (llms.txt convention).

## Customization

- **Nav / sidebar chrome** — `src/lib/layout.shared.tsx` (`DocsLayout` options).
- **Content config** — `source.config.ts` + `src/lib/source.ts`.
- **Search** — server route `src/routes/api/search.ts` (Fumadocs oracle).
- **OG images** — `scripts/generate-og.mjs` (build step).
- **Logo & favicon** — `public/` assets.

## Deploy

Served by a Cloudflare Worker (`wrangler.toml`, `main =
@tanstack/react-start/server-entry`) on `docs.chmonitor.dev` (preview:
`preview.docs.chmonitor.dev`).

**Architecture constraints (do not regress):**

- Pages are prerendered at build time; the Worker serves static HTML plus the
  dynamic routes (raw `.md`, `/llms*.txt`, `/api/search`, redirects).
- Keep the prerender page list complete in `vite.config.ts` — a render crash on
  any listed page breaks the whole build.
