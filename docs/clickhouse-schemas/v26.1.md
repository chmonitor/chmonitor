# ClickHouse 26.1 System Table Changes

## New Columns

### system.parts

| Column | Description |
|--------|-------------|
| `files` | Array of files in the part (use `length(files)` for file count / fragmentation signals) |

## LLM Context

When generating queries for ClickHouse 26.1+:

- `files` is available in system.parts
- chmonitor `part-info` uses `length(files) AS files_count` with `since: '26.1'`; older variants stub `files_count` as 0
