# ClickHouse 25.12 System Table Changes

## New Columns

### system.mutations

| Column | Description |
|--------|-------------|
| `parts_in_progress_names` | Array(String) — parts currently being mutated |

## Related tables (not in TARGET_TABLES seed list)

- `system.background_schedule_pool` / `system.background_schedule_pool_log` — running / historical background schedule pool tasks (chmonitor configs gate at `since: '25.12'`).

When generating queries for ClickHouse 25.12+:
