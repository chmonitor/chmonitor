# ClickHouse 24.1 System Table Changes

## New Columns

### system.query_log

| Column | Description |
|--------|-------------|
| `query_cache_usage` | Enum8 — how the query used the query cache |

### system.processes

| Column | Description |
|--------|-------------|
| `peak_threads_usage` | UInt64 — peak threads for the running query (availability may lag query_log; see table notes) |

## LLM Context

When generating queries for ClickHouse 24.1+:

- `query_cache_usage` is available in system.query_log
- Prefer VersionedSql gates when selecting version-new columns
