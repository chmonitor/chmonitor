# ClickHouse 26.6 System Table Changes

## New Columns

### system.query_log / system.processes

| Column | Description |
|--------|-------------|
| `client_agent` | Detected AI coding agent (Claude Code, Cursor, Codex, …) that invoked the client |

### system.merges

| Column | Description |
|--------|-------------|
| `current_projection` | Projection currently being merged |
| `current_projection_progress` | Progress of the current projection merge |
| `projections_completed` | Count of projections completed |
| `projections_remaining` | Count of projections remaining |

## LLM Context

When generating queries for ClickHouse 26.6+:

- `client_agent` is available in system.query_log and system.processes
- Projection merge introspection columns are available in system.merges
- chmonitor gates query views and merges configs at `since: '26.6'`
