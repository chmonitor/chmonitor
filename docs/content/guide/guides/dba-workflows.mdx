Operators coming from other DBA tools often look for schema compare, change plans, and TTL inventory. This page is the map of **what ships today** versus **what is not in the dashboard yet**.

<Callout type="warn" title="Recommend-only">
chmonitor does **not** apply schema changes and does **not** edit `config.xml` (or any other ClickHouse server file). Advisor output is copyable SQL and settings you review and run yourself.
</Callout>

## What exists today

| Workflow | Route | What it does |
|---|---|---|
| Settings compare | `/settings-diff` | Compares `system.settings` and `system.merge_tree_settings` across saved hosts, or node vs node on the current cluster. Highlights values that differ and values changed from default. Export as CSV. One saved host with a single node shows an example layout and **Add another host**. |
| Schema compare | `/schema-diff` | Compares table DDL across saved hosts, or node vs node on the current cluster. Recommend-only change plan (copy statements, never apply). One saved host with a single node shows an example layout and **Add another host**. |
| Query advisor | `/advisor` (Query Advisor tab) | Ranked skip-index, projection, partition-key, and `PREWHERE` recommendations for a pasted query or a `query_id`. Recommend-only. |
| Schema & settings lint | `/advisor` (Schema & Settings tab) | Scans a database (or one table) for schema lint and settings findings. Recommend-only. |
| TTL moves vs inventory | `/storage-economics` | Per-table compression, storage policies, and **TTL storage move activity**. This is move history / current economics — not a full TTL and partition health inventory. |
| Explorer DDL | `/explorer` | Shows the `CREATE TABLE` statement and schema for the **selected host** (`?host=`). Single-host, read-only. |

### Settings compare (`/settings-diff`)

Open **Tools → Settings Diff**. Compare saved hosts, or pick two cluster nodes when the current host has 2+ replicas. Filter to rows that differ, or to settings changed from default. One saved host with a single node shows an example layout and **Add another host**. The page is gated by the `settings` feature id — see [Settings](/guide/features/settings).

Nothing on this page writes to ClickHouse. To change a setting, use `SET`, `ALTER TABLE … MODIFY SETTING`, or edit the server config yourself.

### Schema compare (`/schema-diff`)

Open **Tools → Schema Compare**. Pick a source and target host (or two nodes of the current cluster). The page lists tables that differ and shows side-by-side `CREATE TABLE` plus a copyable recommend-only plan. It never applies DDL.

### Advisor (`/advisor`)

Open **Queries → Advisor**. Two tabs:

- **Query Advisor** — paste SQL or look up a `query_id` from `system.query_log`.
- **Schema & Settings** — scan a database or table for lint findings.

The same recommend-only engine is available from the [AI agent](/guide/ai-agent) and the MCP server. There is no Apply button.

### Storage economics (`/storage-economics`)

Open **System → Storage Economics**. Three tables:

- Compression by table (from `system.parts`)
- Storage policies
- TTL storage moves (parts that already moved because of TTL)

The inventory of *every* table's TTL expression, partition health, and "should this table have a TTL?" is **not** this page. See [Gaps](#gaps-not-shipped).

### Explorer single-host DDL (`/explorer`)

The [Data Explorer](/guide/features/explorer) shows `CREATE TABLE` for the table on the **current host**. Cross-host or node-vs-node DDL compare lives on `/schema-diff`.

<Callout type="info" title="Read-only explorer">
The explorer cannot create, alter, or drop objects.
</Callout>

## Gaps (not shipped)

These DBA workflows are **not** in the dashboard today. They are described here so evaluators do not look for them on the pages above. They are not scheduled work and have no open tracking issues.

| Gap | What is missing |
|---|---|
| TTL and partition health inventory | `/storage-economics` is move history and current economics, not every table's TTL expression or partition health. |
| Schema advisor on Explorer | Schema lint lives on `/advisor` (Schema & Settings tab), not inline on Explorer. |

Until those exist, use `/schema-diff`, `/settings-diff`, `/advisor`, `/storage-economics`, and `/explorer` as listed above. This guide will point at new routes if they ship.
