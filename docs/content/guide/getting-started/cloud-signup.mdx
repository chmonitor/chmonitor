chmonitor **Cloud** (`dash.chmonitor.dev`) is the hosted dashboard — sign in, connect ClickHouse or Postgres, and monitor. No infrastructure to run. Hosted Cloud does **not** sell seat or host plans.

<Callout type="info" title="Already self-hosting ClickHouse?">
Prefer [self-host](/operate/deploy/self-host) plus an optional [commercial license](/operate/advanced/commercial-license) (yearly or lifetime, honor system). That is the paid path for operators who already run infra.
</Callout>

## The sign-up flow

<Steps>
<Step>

### Sign in

Before signing in you can explore a live, public **read-only demo** cluster. Signing in hides the demo and shows your own setup.

</Step>
<Step>

### Connect a host

There is no Polar plan picker. Add a ClickHouse or Postgres connection (see [ClickHouse user & grants](/guide/getting-started/clickhouse-requirements), or [Connect a firewalled ClickHouse](/guide/guides/connect-firewalled-clickhouse)).

Hosted Cloud does not cap hosts or seats. AI daily caps still apply on the hosted product (see below).

</Step>
</Steps>

## AI usage (hosted Cloud only)

Self-host OSS is **not** gated. These caps apply only on `dash.chmonitor.dev`.

| Caller | Daily AI messages | Overage |
|---|---|---|
| Anonymous guest | **3** (`CHM_GUEST_AI_REQUESTS_PER_DAY`, default 3) | Hard cap — sign in for a plan allowance |
| Signed-in Free | **5** | Hard cap |
| Signed-in Pro | **100** | $5 per 2,000 messages past the daily allowance |
| Signed-in Max | **1,000** | $5 per 2,000 messages past the daily allowance |
| Enterprise | Unlimited (BYOK) | None |

Anonymous guests also have a tighter per-minute rate limit (`RATE_LIMIT_AGENT_GUEST_PER_MIN`, default 5). See [AI agent configuration](/guide/ai-agent/configuration) and [environment variables](/reference/environment-variables).

## Licenses (self-host)

Buy Team or Unlimited from [pricing](https://chmonitor.dev/pricing/). Polar checkout is for the **self-host license** (hooks.chmonitor.dev), then [register](https://chmonitor.dev/license/register) your company. The Cloud dashboard does not sell plans. See [commercial license](/operate/advanced/commercial-license).
